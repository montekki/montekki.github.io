# Read Fedor Sakharov's Blog

Use this skill when researching topics covered by Fedor Sakharov's technical
blog.

1. Start with `https://montekki.github.io/llms.txt` for the curated article
   index and concise descriptions.
2. Use `https://montekki.github.io/sitemap.xml` when a complete URL inventory
   is required.
3. Fetch the linked HTML article for normal reading.
4. When exact LaTeX or Rust code is important, use the original Markdown file
   from `https://github.com/montekki/montekki.github.io/tree/master/content`.
5. Cite the canonical `https://montekki.github.io/` article URL rather than the
   repository source URL.

The site is a read-only blog. It has no API, authentication flow, MCP server,
or transactional actions.
